# 🎬 Filmory

- * 영화 검색, 키워드 기반 AI 추천, AI 리뷰 작성 및 개인별 감상 기록을 제공하는 영화 웹사이트 *

- **배포 주소:** 추후 추가 예정
- **사용 기술:** HTML, CSS, JavaScript, Supabase, Gemini API, Vercel

## 📌 프로젝트 소개

**Filmory**는 `Film`과 `Memory`를 결합한 이름으로, 사용자가 새로운 영화를 발견하고 자신만의 영화 감상을 기록할 수 있도록 돕는 웹사이트입니다.

사용자는 영화 정보를 검색하고, 원하는 분위기나 장르 등의 키워드를 입력하여 AI 영화 추천을 받을 수 있습니다. 또한 계정에 로그인하여 영화별 별점과 리뷰를 작성하고, 자신만의 영화 감상 기록을 저장할 수 있습니다.

## ✨ 주요 기능

- **영화 검색 및 정보 조회**
  - 영화 제목을 검색하여 포스터, 줄거리, 장르, 개봉일, 평점 등의 정보를 확인할 수 있습니다.

- **키워드 기반 AI 영화 추천**
  - 사용자가 원하는 분위기, 장르, 소재 등을 입력하면 Groq API가 조건에 맞는 영화를 추천합니다.
  - 추천 영화와 함께 추천 이유를 제공합니다.

- **AI 영화 리뷰 도우미**
  - 사용자가 입력한 짧은 감상이나 키워드를 자연스러운 영화 리뷰로 정리합니다.
  - 사용자는 AI가 정리한 리뷰를 직접 수정한 후 저장할 수 있습니다.

- **회원가입 및 로그인**
  - Supabase Auth를 이용하여 회원가입과 로그인 기능을 제공합니다.
  - 로그인한 사용자별로 리뷰 데이터를 구분하여 관리합니다.

- **개인별 영화 리뷰 저장**
  - 영화별 별점과 리뷰를 작성하여 자신의 계정에 저장할 수 있습니다.
  - 작성한 리뷰를 조회, 수정하거나 삭제할 수 있습니다.

- **나의 영화 기록**
  - 사용자가 작성한 리뷰를 모아서 확인할 수 있습니다.
  - 개인 영화 다이어리처럼 감상한 작품과 생각을 관리할 수 있습니다.

## 🛠️ 사용 기술

- **Frontend:** HTML, CSS, JavaScript
- **Authentication:** Supabase Auth
- **Database:** Supabase
- **AI:** Gemini API
- **Backend & Deployment:** Vercel Serverless Functions, Vercel
- **Version Control:** GitHub
